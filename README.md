# 🌿 CozyRefuge

> A cozy, modern web space designed for comfort, community, and calm.

---

## 📖 Overview

**CozyRefuge** is a responsive web project built to provide users with a clean, relaxing digital sanctuary. Designed with modern web standards and responsive layout practices, this project blends crisp frontend aesthetics with a scalable backend architecture.

---

## 🛠️ Tech Stack

| Domain | Technologies Used |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript (ES6+), PrimeFlex CSS |
| **Backend** | Node.js, Express.js |
| **Development Tools** | VS Code |
